# 태그 필터링 기능 정의서

> 초기 아이디어. 인터뷰를 거쳐 `spec-fixed.md`로 확정한다.

## 기능 개요

노트에 붙은 태그를 한곳에 모아 보여 주고, 태그를 누르면 해당 태그가 달린 노트만 노트 리스트에 나열한다.

## 기능 요구사항

- 모든 노트의 태그 정보를 모아서(중복 제거) 별도 영역에 보여 준다
- 태그를 누르면 그 태그가 달린 노트만 노트 리스트에 표시한다

## 비고

- 선행 기능: `docs/features/tag/` (노트에 태그 추가·삭제). 그 PRD에서 필터링은 Out of Scope였다.
