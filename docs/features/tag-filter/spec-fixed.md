# 태그 필터링 확정 정의서

원본 `spec.md`에 대한 인터뷰 결과를 반영한 확정본이다. 사용자가 직접 답한 항목(★)과, 인터뷰에서 따로 묻지 않고 추천안으로 정한 항목(☆)을 구분해 표기한다. ☆ 항목은 검토 후 바꿔도 된다.

선행 기능은 [`../tag/`](../tag/spec-fixed.md)(노트에 태그 추가·삭제)이며, 그 PRD가 "태그 필터링·태그 클릭 동작"을 Out of Scope로 남겨 두었다. 이 문서는 그 항목을 별도 feature로 다룬다.

## 기능 개요

모든 노트의 태그를 한곳(사이드바 상단)에 칩으로 모아 보여 주고, 칩을 누르면 노트 리스트에 그 태그가 달린 노트만 표시한다.

## 용어 정의 (Ubiquitous Language)

| 용어        | 의미                                                                                    |
| ----------- | --------------------------------------------------------------------------------------- |
| 태그        | 노트의 `tags` 배열에 든 문자열 하나. 기존 `tag` 기능이 정의한 것을 그대로 쓴다.         |
| 태그 모음   | 모든 노트의 태그를 중복 없이 모아 칩으로 보여 주는 사이드바 상단 영역.                  |
| 태그 칩     | 태그 모음 안의 버튼 하나. (편집기의 태그 칩과는 다른 컴포넌트이며, 클릭 시 필터를 토글) |
| 필터        | 노트 리스트를 특정 태그가 달린 노트로 좁히는 상태.                                      |
| 선택된 태그 | 지금 필터로 켜져 있는 태그. 없으면 `null`(필터 꺼짐).                                   |
| 선택된 노트 | 기존 `selectedNoteId`가 가리키는 편집 중인 노트. **선택된 태그와 별개의 개념이다.**     |

## 확정 사항

### 선택 방식

- ★ 단일 선택이다. 한 번에 태그 하나만 활성화한다.
- ☆ 다른 태그 칩을 누르면 선택된 태그가 교체된다.
- ★ 선택된 칩을 다시 누르면 필터가 해제된다. 별도의 "전체" 버튼은 두지 않는다.
- ☆ 필터 상태는 새로고침하면 초기화된다(`localStorage`, URL 쿼리에 저장하지 않는다).

### 태그 모음 (집계)

- ★ 대소문자를 구분하지 않고 합친다. `React`(노트 A)와 `react`(노트 B)는 칩 하나다.
- ☆ 칩에 표시하는 표기는 노트 리스트 순서상 가장 먼저 나온 표기를 쓴다.
- ★ 칩은 가나다/알파벳순으로 정렬하고, 노트 개수는 표시하지 않는다.
- ☆ 정렬은 대소문자를 무시한 비교로 한다(`localeCompare`, 한국어 로케일).
- ☆ `tags`가 없는 기존 노트는 `[]`로 간주한다(`tag` 기능과 동일).
- ★ 태그가 하나도 없으면 태그 모음 영역 자체를 렌더하지 않는다. 로딩·에러 상태에서도 렌더하지 않는다.
- ☆ 태그 모음은 서버에 별도 요청하지 않고 `notes` 상태에서 파생 계산한다. `/tags` 리소스와 API 변경은 없다.

### 필터링

- ★ 필터링 기준은 "노트의 `tags` 중 선택된 태그와 대소문자 무시로 같은 것이 하나라도 있다"이다.
- ☆ 필터는 노트 리스트의 표시 목록에만 영향을 준다. 노트 데이터(`notes`)와 서버는 건드리지 않는다.
- ☆ 리스트 상단의 "노트 N개" 문구는 필터링된 노트 수를 보여 준다.
- ★ 선택된 태그가 더 이상 어떤 노트에도 없으면(편집기에서 태그를 지우거나 마지막 노트를 삭제) 필터가 자동으로 해제되어 전체 목록으로 돌아간다. 존재하지 않는 태그로 필터가 걸린 채 "노트가 없습니다"만 보이는 상태는 만들지 않는다.
- ☆ 위 자동 해제는 상태를 지우는 `useEffect`가 아니라, "선택된 태그가 유효할 때만 적용"하는 파생 계산으로 구현한다.

### 편집기와의 관계

- ★ 필터는 노트 리스트 표시에만 영향을 준다. 현재 편집 중인 노트(`selectedNoteId`)가 필터 조건에 맞지 않아도 편집기는 그대로 유지한다. 리스트에서는 해당 노트의 선택 표시가 보이지 않을 뿐이다.
- ☆ 필터 변경은 `selectedNoteId`, `isCreating`을 바꾸지 않는다.
- ☆ 편집기에서 저장해 태그가 바뀌면 `notes`가 갱신되고, 태그 모음과 필터 결과가 즉시 다시 계산된다.

### UI

- ★ 태그 모음은 사이드바 상단, 노트 리스트 바로 위에 칩으로 나열한다. 칩이 많으면 사이드바 폭 안에서 줄바꿈한다.
- ☆ 칩은 `<button>`이고 선택 상태를 `aria-pressed`로 노출한다.
- ☆ 선택된 칩은 `surface_container_highest` 배경(디자인 시스템의 "선택됨" 표현)으로 구분한다. 액센트 색은 장식에 쓰지 않는다.
- ☆ 칩, 영역 구분은 1px 테두리·하드코딩 그림자 없이 배경색 차이와 `@theme` 토큰으로 표현한다. 스타일 작업은 `design-system` 스킬로 진행한다.
- ☆ UI 텍스트는 한국어. 태그 모음 영역에 라벨이 필요하면 `label-md` + `uppercase` 규칙을 따른다.

### 노트 카드 (`NoteItem`)

- ★ 리스트의 각 노트 카드에 그 노트의 태그를 배지로 보여 준다.
- ★ 필터로 선택된 태그와 같은 배지는 하이라이트한다.
- ☆ 배지는 노트에 저장된 순서와 표기 그대로 모두 보여 준다. 줄바꿈은 하되 개수 상한과 "+N" 접기는 없다.
- ☆ 태그가 없는 노트(`tags` 없음 포함)는 배지 영역을 렌더하지 않는다.
- ☆ 하이라이트 판정은 태그 모음과 같은 규칙(대소문자 무시)이다. `React` 필터에서 `react` 배지도 하이라이트된다. 필터가 꺼져 있으면 하이라이트는 없다.
- ☆ 배지는 표시 전용이다. 클릭, 호버 동작이 없고 `<button>`이 아니다(필터 조작은 태그 모음 칩으로만 한다).
- ☆ 카드 배지의 모양은 태그 모음 칩, 편집기 칩과 구분되는 더 작은 읽기 전용 스타일이다. 하이라이트는 `surface_container_highest` 배경 등 디자인 시스템 토큰으로 표현하고 액센트 색은 쓰지 않는다.
- ☆ `NoteItem`은 계속 상태 없는 표현 컴포넌트다. 하이라이트 대상 태그는 props로 받는다.
- 이 변경은 선행 `tag` 기능의 "목록(`NoteItem`)에는 태그를 표시하지 않는다" 결정을 이 feature에서 뒤집는 것이다.

### 에러 처리

- ☆ 필터는 클라이언트 계산뿐이라 새로 생기는 실패 경로가 없다. 노트 로딩 실패는 기존 `NoteList`의 오류 표시를 따른다.

### 성능

- ☆ 노트 수가 수백 개 이하인 소규모 앱이므로 `useMemo` 없이 렌더마다 계산한다(프로젝트 컨벤션: Context 값·계산 메모이제이션 없음).

## 변경 대상 영역 (구현 순서 후보, 설계는 PRD에서 확정)

- 필터 상태(`selectedTag`)를 어디에 둘지: `App`(기존 UI 선택 상태와 동일, props로 전달) 후보
- 태그 집계·필터 로직: 순수 함수 또는 커스텀 훅 후보
- 태그 모음 컴포넌트 신규, `NoteList` 수정(필터 적용), `NoteItem` 수정(태그 배지, 선택 태그 하이라이트)

위 구조 결정은 단계 2(PRD, ADR)에서 3안 비교 후 확정한다.

## 범위 밖 (이번에 만들지 않음)

- 다중 태그 선택(AND/OR)
- 태그별 노트 개수 표시, 노트 많은 순 정렬
- 필터 상태의 저장(새로고침 유지, URL 공유)
- "전체" 버튼 등 별도 필터 해제 컨트롤
- 카드 안 태그(배지) 클릭으로 필터 (배지는 표시와 하이라이트 전용)
- 편집기의 태그 칩 클릭으로 필터
- 태그 이름 변경·삭제 등 관리 기능, 태그 검색·자동완성
- 서버 쿼리(`tags_like`) 기반 필터링, `/tags` 리소스

## 테스트 관점 (구현 시 확인할 것)

- 여러 노트의 태그가 중복 없이 모여 가나다순으로 보인다
- `React`/`react`가 칩 하나로 합쳐지고, 누르면 두 노트가 모두 나온다
- 칩을 누르면 해당 태그가 달린 노트만 리스트에 남고 "노트 N개"가 줄어든다
- 선택된 칩을 다시 누르면 전체 목록으로 돌아간다
- 다른 칩을 누르면 필터가 교체된다
- 모든 노트에 태그가 없으면(또는 `tags` 필드 자체가 없으면) 태그 모음이 보이지 않는다
- 필터 중 해당 태그를 편집기에서 지우고 저장하면 필터가 자동 해제된다
- 필터 중 해당 태그의 마지막 노트를 삭제하면 필터가 자동 해제된다
- 필터 조건에 맞지 않는 노트를 편집 중이어도 편집기가 유지된다
- 선택된 칩에 `aria-pressed="true"`가 설정된다
- 노트 카드에 그 노트의 태그가 저장 순서대로 배지로 보이고, 태그가 없는 노트는 배지 영역이 없다
- 필터를 켜면 카드의 같은 태그 배지만 하이라이트되고(대소문자 무시), 필터를 끄면 하이라이트가 사라진다
- 카드 배지를 눌러도 필터나 선택 노트가 바뀌지 않는다(배지 클릭은 카드 클릭과 같이 노트 선택만 일어난다)
