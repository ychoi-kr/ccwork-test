# 버튼

| 종류             | 스타일                                                                                     |
| ---------------- | ------------------------------------------------------------------------------------------ |
| Primary          | `tertiary` → `tertiary_container` 그라디언트, 텍스트 `on_tertiary`, `rounded-md`(0.375rem) |
| Secondary        | `surface_container_high` 배경, `on_surface` 텍스트, 테두리 없음                            |
| Tertiary (Ghost) | 배경 없음, 텍스트 `tertiary`, hover 시 액센트 색 2% 배경                                   |

액센트는 의도 있는 동작에만. 한 화면에 Primary는 하나가 기본이다.
