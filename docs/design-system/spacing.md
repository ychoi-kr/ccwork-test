# 간격

기준 리듬은 **1.4rem (`spacing.4`)**.

| 토큰         | 값      | 용도                         |
| ------------ | ------- | ---------------------------- |
| `spacing.1`  | 0.35rem | 라벨 ↔ 입력 간격             |
| `spacing.2`  | 0.7rem  | 제목 ↔ 본문 (세로 리듬)      |
| `spacing.4`  | 1.4rem  | 목록 항목 사이 기본 간격     |
| `spacing.10` | 3.5rem  | 큰 섹션 간격 ("Atmospheric") |

여백은 구조다. 애매하면 늘린다.
