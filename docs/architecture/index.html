4. 저장 시퀀스 (생성/수정)

서버 응답을 받은 뒤에 로컬 상태를 갱신합니다(낙관적 업데이트 아님). 실패하면 예외가 호출한 컴포넌트까지 전파되고 console.error로만 기록됩니다. 

sequenceDiagram
  actor User
  participant Editor as NoteEditor
  participant Ctx as NotesContext
  participant API as api/notes.ts
  participant DB as json-server
  participant App
  participant List as NoteList

  User->>Editor: 저장 클릭
  Editor->>Editor: handleSave, setSaving(true)
  Editor->>Ctx: createNote(title, content) / updateNote(id, updates)
  Ctx->>API: createNote / updateNote
  API->>DB: POST / PATCH /notes
  DB-->>API: 저장된 Note
  API-->>Ctx: Note
  Ctx->>Ctx: setNotes(prev → 추가/교체)
  Ctx-->>List: notes 변경으로 리렌더
  Ctx-->>Editor: 완료
  Editor->>App: onDone()
  App->>App: setIsCreating(false)
  Note over Editor,Ctx: 실패 시 throw → Editor가 console.error

5. 삭제 시퀀스

sequenceDiagram
  actor User
  participant Item as NoteItem
  participant List as NoteList
  participant Ctx as NotesContext
  participant API as api/notes.ts
  participant DB as json-server

  User->>Item: 삭제 클릭 (stopPropagation)
  Item->>List: onDelete(id) → handleDelete
  List->>Ctx: deleteNote(id)
  Ctx->>API: deleteNote(id)
  API->>DB: DELETE /notes/:id
  DB-->>API: 200
  Ctx->>Ctx: setNotes(prev → filter)
  Ctx-->>List: 리렌더
  Note over List,Ctx: 실패 시 List가 console.error
